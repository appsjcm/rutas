# Rutas

Aplicación web para importar GPX, preparar enlaces de Maps, grabar recorridos GPS y exportar GPX, KML, GeoJSON y CSV.

Web: https://appsjcm.github.io/rutas/

Los archivos GPX se procesan en el dispositivo. Para grabar, permite el acceso a la ubicación y mantén la página abierta en primer plano.

El repositorio contiene únicamente la aplicación; las rutas personales se cargan desde el dispositivo.
